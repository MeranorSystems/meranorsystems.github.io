Install WayVeil

Add WayVeil to your iPhone Home Screen.

For the first tester environment, installation uses Safari’s real Add to Home Screen flow. WayVeil coaches the steps; it does not fake an Apple install dialog.

iPhone · Safari · iOS 26 flow

Open the entitled WayVeil page in Safari.

The live W8 handoff will send an authorized tester to the accepted WayVeil PWA URL. W5 does not connect a product build.

Open Safari’s Share menu.

Depending on your Safari tab layout, use the Share button directly or open More and then Share.

Choose Add to Home Screen.

If it is not visible, Safari allows it to be added from Edit Actions.

Keep Open as Web App turned on.

On iOS 26, websites added to the Home Screen open as web apps by default unless the user disables this option.

Tap Add, then launch from Home Screen.

Once W8 connects the real build, the installed app will enter the accepted WayVeil onboarding and LOCAL_GUEST navigation flow.

P

Park before install, update, recovery, or reauthorization.

The install experience is not a driving task. Complete it while stationary before beginning a testing session.
