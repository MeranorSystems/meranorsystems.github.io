Read Safety FirstPrivacy Approach

Public interest ≠ access

Requesting access does not authorize the app.

The eventual live flow will keep the public interest path separate from tester entitlement. Ordinary visitors may express interest; actual Cohort-One access requires an approved, controlled invitation and redemption flow.

1

Interest

A public visitor may request consideration using only information we can justify collecting.

2

Invitation

An approved tester receives a unique bounded invite by link or QR. QR is transport, not a perpetual license.

3

Entitlement

Redemption establishes closed-alpha authorization that remains separate from LOCAL_GUEST navigation identity.

i

W5 adds a mocked invited-tester portal — not live authorization.

You can preview invitation, Active, Expired, Revoked, Suspended, and Install states without creating a real account or entitlement. Security semantics remain held for W6/W7.
