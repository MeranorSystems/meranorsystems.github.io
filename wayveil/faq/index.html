WayVeil/FAQ

FAQ

Short answers to the important questions.

WayVeil is still an alpha product, so the clearest answer is often more useful than the most marketable one.

What is WayVeil?

WayVeil is privacy-first navigation that helps drivers understand known ALPR exposure and compare route choices that can reduce known exposure while still getting where they need to go.

Does “Zero Known ALPR” mean no cameras are on the route?

No. It means zero encounters in the current known/active supported dataset. Unknown, new, moved, inactive, or missing devices can still exist. WayVeil does not claim surveillance-free travel.

Do I need a WayVeil account to navigate?

Not for Cohort One. LOCAL_GUEST is the accepted navigation identity model. Closed-alpha entitlement proves that a tester is authorized; it is not the identity for private navigation activity.

Does the alpha-access layer receive my GPS or route history?

It is not authorized to receive raw GPS, origin/destination, search content, route geometry, route history, navigation-session history, VeilScore / ALPR encounter history, trip history, or Private Session state.

Where does the first alpha work?

The accepted Cohort-One driving boundary is supported Missouri coverage. Other regions should only be added after their own data, runtime, provider, and safety evidence is accepted.

How will I install it?

The first tester distribution target is an installable PWA using iPhone/Safari first. The actual iOS install remains Apple’s Add to Home Screen / Open as Web App flow; WayVeil will provide an accurate install coach rather than a fake system dialog.

Can I use it with the phone locked or in the background?

That is not a Cohort-One guarantee. The accepted first testing envelope keeps the PWA foregrounded with the screen on. Background/lock survival requires separate proof before we claim support.

Does WayVeil have live traffic?

Not as an accepted current feature claim. The product roadmap can add traffic/road context where supported, but the public site will not advertise it before it is actually accepted.

Is the Join Alpha form live right now?

No. In W5 it is a preview-only interface and sends no data. Live collection will be enabled only after the hosted access and privacy behavior are explicitly accepted.

Who builds WayVeil?

WayVeil is a Meranor Systems project focused on consumer navigation with automotive privacy as a first-class route consideration.
